Video Publisher

Privacy Policy

Effective 31 October 2026 · Last updated 31 October 2026

Video Publisher is a private, single-user tool operated by Heck Holdings ("the operator") to publish its own videos to its own YouTube channel. It is not offered to the public and has no end users other than the operator. This policy explains what the tool accesses and what it does with it.

1. What it accesses

When the channel owner authorises the tool through Google's consent screen, the tool receives an OAuth 2.0 credential for that one Google account, with two scopes:

  • youtube.upload — used to upload video files the owner has produced to the owner's channel, and to set their title and description.
  • youtube.readonly — used only to read the channel's own name and identifier, so the tool can verify it is about to publish to the correct account.

The tool does not request, access, or store data belonging to any other person: no viewers, no commenters, no subscribers, no third-party channels, and no Google account other than the authorised one.

2. What is stored, and where

  • The OAuth refresh token is stored as a file on the operator's own computer (dist/yt_token.json). It never leaves that machine except in calls to Google's API.
  • Video files, captions and a local publishing record (which episode went to which platform, and when) are stored on the same machine.
  • Nothing is stored on a server operated by the tool. There is no database in the cloud, no analytics service, and no third-party processor.

3. What is not done with it

The tool does not sell, rent, share, transfer, or disclose the authorisation token, the channel data, or any derived information to any third party. It is not used for advertising, profiling, or training machine-learning models. No human other than the operator can access the stored credential.

4. This website

These pages are static. They set no cookies, run no scripts, and include no analytics or tracking pixels. The hosting provider may keep standard server logs (IP address, user agent, timestamp) as any web server does; the operator does not read or use them.

5. YouTube API Services

This application uses YouTube API Services. By using it, the operator agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

6. Retention and deletion

The authorisation token is retained only while the tool is in use. It can be revoked at any time at myaccount.google.com/permissions — revoking it immediately invalidates the tool's access. Deleting dist/yt_token.json on the operator's machine removes the stored credential permanently.

Videos already published remain on the YouTube channel under the channel owner's control and can be removed from YouTube Studio in the normal way.

7. Children

The tool is not directed at children and is not made available to anyone other than its operator.
